# Regrat / Dandelion — professional EU parameters

Source: Intersemillas, Diente de león (Taraxacum officinale), Baby Leaf.

- Seeds per gram: 1500
- Seed rate: 5–8 kg/ha = 0.5–0.8 g/m²
- Germination temperature: 15–20 °C
- Germination time: 7–15 days
- Sowing depth: 0.5 cm
- Sowing season: autumn and early spring
- Useful parts: leaves and flowers; tender dark-green leaves are suitable for salads

GrowMaster should use these values as the primary professional EU sowing reference for Regrat. Existing harvest timing remains an application agronomic estimate unless a supplier source explicitly states a baby-leaf harvest cycle.
